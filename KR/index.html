Про проєкт

Ця сторінка створена в межах контрольної роботи. Вона демонструє використання трьох різних шрифтів з Google Fonts, адаптивний дизайн та сучасні технології верстки (CSS Grid + Flexbox).

Можливості

Адаптивність

Сторінка коректно відображається на будь-яких пристроях.

Grid Layout

Використано CSS Grid для побудови сітки карток.

Flexbox

Flexbox застосовано для навігації та вирівнювання.

Шрифти

Три різні шрифти з Google Fonts для заголовків, тексту й коду.
